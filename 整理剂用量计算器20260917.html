模型与使用须知

响应面模型（7 因子）： sa = B + (0.149052·c + 0.00405792)·v，其中
B = 2.80246 + 0.248919·d − 1.33856·La + 0.286129·La² + 0.00289302·t1 − 0.0702392·t2 + 0.0011104·t2² + 0.0208514·t3 − 0.000585764·t1·t3 − 0.000759193·t3² − 12.4612·c + 4.82094·c·La

必须知道的五条：

  1. c 是质量分数，不是 g/L。nb 中的注释写作 g/L，但只有按质量分数（0.035 = 3.5%）代入，v×c 才等于克数。
  2. v 在模型中只有线性项，意味着"越加越好"没有上限。若实验中已观察到平台（饱和），高目标 sa 下本工具会系统性高估用量。
  3. La 二次项在 2.04 kg 处翻头，模型预测超过该负载后用量反而下降——这是外推假象，不可用于实机大负载。
  4. 放大倍数约 108：sa 的模型误差会被原样放大 108 倍变成 mL，所以务必用 RMSE 给出区间，不要只报单点值。
  5. d 与 t3 的因子映射需核对：两者都属"水蒸汽"时间，系数相差约 20 倍，若在 JMP 中写反，结果会完全不同。
