# 日常工具箱

## 包含工具

| 工具 | 文件 | 说明 |
|---|---|---|
| 管吸液体量计算器 | `吸液量计算器20261010.html` | 层流吸液模型，计算毛细管吸液体积与吸液曲线 |
| 硅油 RC 膜缓释速率计算器 | `硅油RC膜缓释速率计算器.html` | 统一扩散–溶解模型：硅油/RC 膜物性、膜厚与环境条件 → 缓释通量、累积释放曲线、残余浓度 |
| 整理剂用量计算器 | `整理剂用量计算器20260917.html` | 逆解：由目标平整度 sa 与干燥/蒸汽工艺时间，反算所需整理剂用量 v |
